# Autonomous-Robot-Car

## Overall
A mecanum robot car can move autonomously in a controlled indoor environment, make movement decisions, detect obstacles, and avoid collisions.

## Description
Hardware: Keyestudio KS0560 4WD Mecanum Robot Car, RPLIDAR C1, FIT0450 (DC Motor with encoder - SJ01), 3D printing mounting parts.
